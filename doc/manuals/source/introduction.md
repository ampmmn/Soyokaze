# Introduction

## What is this app.

```{only} soyokaze
{{ project }} はWindows上で動作するコマンドライン型のランチャーツール

```

```{only} not soyokaze
{{ project }} はWindows上で動作するコマンドライン型のランチャーツール

```

![](image/introduction/overview.gif)

{{ project }}は、キーボードからアプリケーションやファイルをすばやく開くためのランチャーです。

呼び出しキーを押して入力画面を表示し、目的のキーワードを入力してEnterキーを押すだけで操作できます。

例えば、よく使うアプリケーションやWebページに`memo`や`github`のような覚えやすいキーワードを登録しておくと、毎回スタートメニューやブラウザーのお気に入りを探す必要がなくなります。

ファイルやフォルダ、URLなどをコマンドとして登録して、手軽に開くことができます。

コマンドを登録していない場合でも、ファイルパスやURLを入力して直接開いたり、電卓やクリップボード履歴などの機能を利用したりできます。まずは[基本的な使い方](/usage/how_to_use)を参照してください。
