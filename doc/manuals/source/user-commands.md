# Commands

本アプリで作成できる、利用者が登録するコマンドについて説明します。

コマンドは、入力画面からキーワードを入力して実行する操作です。初めて登録する場合は、まず[通常コマンド](/user-command/shellexecute)を使ってアプリケーションやWebページを起動する方法を試してください。

目的に応じたコマンドの選び方は次のとおりです。

- アプリケーション、ファイル、フォルダ、URLを開く: 通常コマンド
- Web検索を行う: Web検索コマンド
- 定型文を入力する: 定型文グループコマンド
- 複数のコマンドをまとめて実行する: グループコマンド
- 入力内容を加工してから実行する: フィルター、正規表現、エイリアス
- ウインドウを切り替えたり配置したりする: ウインドウ操作系のコマンド

各コマンドの詳細ページでは、設定項目の意味と利用例を説明しています。すべての種類を理解する必要はありません。目的に合う種類を一つ選んで登録してください。
