# 実行結果確認コマンド

プログラムを実行し、標準出力または出力ファイルをランチャーのプレビューウインドウに表示します。ファイルの実行が対象です。フォルダやURLを直接実行することはできません。

## 設定

![](../image/user-command/output-preview/edit-command.png)

- `コマンドの名前`  
入力画面からコマンドを呼び出すキーワードです。
- `説明`  
コマンドの説明を入力します。
- `実行するファイルのパス`  
実行するファイルを指定します。フォルダやURLは指定できません。
- `パラメータ`  
実行プログラムに渡す引数を指定します。実行時の入力は `$*`、`$1`、`$2` などで参照できます。
  - `結果表示に用いる出力` で「`$output` のファイル」を選ぶ場合、引数に `$output` を含めてください。実行時にアプリケーションのユーザーフォルダ内に作成した一時ファイルのパスに置き換えられます。
- `ウインドウの表示方法`  
通常表示、非表示、最小表示、最大表示から選択します。
- `作業フォルダ`  
プログラムの作業フォルダを指定します。空欄の場合は実行プログラム側の既定の作業フォルダが使われます。
- `結果表示に用いる出力`  
「標準出力」または「`$output` のファイル」を選択します。
- `出力ファイルの拡張子`  
「`$output` のファイル」を選択した場合に、一時出力ファイルに付ける拡張子です。初期値は `.txt` です。Webコンテンツとして表示する場合は、必要に応じて `.html` などを指定してください。
- `結果表示方法`  
テキストとして表示するか、Webコンテンツとして表示するかを選びます。テキスト表示ではUTF-8として有効な出力をUTF-8、それ以外をSJISとして読み取ります。Webコンテンツ表示ではHTMLファイルをそのままWebView2で開きます。
- `タイムアウト`  
プログラムの終了を待つ時間をミリ秒で指定します。2～60000ミリ秒の範囲で指定できます。時間内に終了しなかった場合は、実行中のプロセスを終了して通知します。
- `終了コードが0でなくても結果表示を試みる`  
終了コードが0以外の場合も結果の読み込みと表示を試みます。オフの場合は、終了コードが0以外のとき結果を表示しません。

## 実行時の操作

|押下キー|動作|
|--|--|
|`Enter`|コマンドを実行します。結果プレビュー表示中はプレビューを閉じます。|
|`Ctrl+Enter`|実行ファイルが置かれているフォルダを表示します。|
|`Alt+Enter`|実行ファイルのプロパティを表示します。|
|`Shift+Enter`|結果をクリップボードにコピーして、プレビューを閉じます。|

タイムアウトや起動失敗の場合は結果を表示しません。終了コードが0以外の場合は、設定で「終了コードが0でなくても結果表示を試みる」を有効にすると、結果の読み込みと表示を試みます。実行結果を表示している間は、別の実行結果確認コマンドを実行できません。

Webコンテンツ表示中にリンクをクリックすると、リンク先は本アプリ内ではなく、設定されている外部ブラウザーで開きます。

表示を閉じると、結果表示に使った一時ファイルは削除されます。アプリケーションを終了した場合も、一時ファイルは後始末の対象になります。
