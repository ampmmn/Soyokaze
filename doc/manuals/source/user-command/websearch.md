# Web Search Command

Web検索を行うためのコマンド。  
コマンドを実行すると、システムの既定のブラウザでWeb検索を行う。

GoogleやTwitterなどの検索に対して名前を付けて、その名前で検索サイトを使い分けることができる。  
例えば、Google検索に`g`という名前を付けて、`g (検索ワード)` で検索を実行できる。

## Description

![](../image/user-command/web-search/new-command.png)

- `コマンドの名前`  
入力画面からWeb検索コマンドを実行するためのキーワード
- `説明`  
コメント表示欄に記載される文字列。  
空欄にした場合、`検索URL`の内容がコメント表示欄に記載される。
- `検索URL`  
検索するためのURLを指定する。  
`$*`を含めると、その部分が検索キーワードに置き換えられる。
  - Google検索を行う場合は、`https://www.google.com/search?q=$*`と指定すればよい
    - 例えば「Soccer」というキーワードを指定した場合、 `https://www.google.com/search?q=Soccer` となる
- `▼`  
主要な検索エンジンのURLを選択して、入力することができる  
Google/Bing/DuckDuckGo/X/Amazon/Youtube が選択できる
- `常に検索候補として表示する`  
チェックすると、コマンド名を入力しなくても、検索ワードを入れるだけで候補として表示されるようになる  
![](../image/user-command/web-search/shortcut-search.png)
  - この場合[弱一致](/others/about-matching.md#weak-match)扱いとなる  
  - 検索URLに`$*`を入力したときだけ表示される  
- `検索結果を表示するアプリケーション`  
コマンドを実行したときに検索結果を表示するアプリケーションを以下の2つから選択できる
  - `既定のWebブラウザ`  
システムに関連付けられたWebブラウザで検索結果を表示する。  
一般的にはEdge/Chrome/Firefoxなどが使われることが多い。これらのタブブラウザを使っている場合、コマンド実行のたびにタブが追加される。
  - `専用検索ウインドウ`  
アプリ内で専用のウインドウを表示し、そのウインドウ内で検索結果を表示する。  
1つのWeb検索コマンドにつき、1つのウインドウが割り当てられる。コマンド実行のたびにタブが増えることなく、ウインドウが流用される。  
(コマンドを実行すると、前回の表示が消えて、新しい検索結果が表示される)
- `ウインドウのタイトル文字列`  
`専用検索ウインドウ`のタイトル文字列を指定する。
- `ホットキー`  
コマンドを呼び出すキーバインドを設定できる。  
設定したキーを押下すると、入力欄が表示され、コマンド名が入力された(キーワードで絞り込みができる）状態になる
- 左上のアイコン欄  
アイコン欄を右クリックすると、コンテキストメニューが表示される。  
![](../image/common/web-search-command-context-menu.png)
  - `アイコンを変更する`  
選択すると、ファイルを選択するダイアログが表示される。画像ファイルを選択すると、その画像をアイコンとして使用することができる。
    - ローカルパスのほか、URLを直接指定することも可能
    - PNG/JPEG/GIF/BMP/TIFF/ICO/SVG形式のファイルが利用可能。SVGは静止画像として扱われる
    - 検索サイトごとにアイコンを変えると視認性が高まるのでおすすめ
  - `URLからファビコンを取得する`    
選択すると、`検索URL`のファビコンを取得し、アイコンとして設定する。
  - `アイコンを初期状態に戻す`  
選択すると、変更したアイコンを元に戻すことができる

## Per-Key Behavior

#### `既定のWebブラウザ`を使う場合

|押下キー|動作|
|--|--|
|`Enter`|既定のWebブラウザで検索を実行する|

#### `専用検索ウインドウ`を使う場合

|押下キー|動作|
|--|--|
|`Enter`|専用検索ウインドウで検索を実行する|
|`Ctrl-Enter`|既定のWebブラウザで検索を実行する|
