# Jump List Pinned Items

Windowsのジャンプリストにピン留めされた項目を検索候補として表示する。候補を実行すると、Windowsの関連付けに従って項目を開く。

![](../image/adhoc-command/shell-destinations/input.png)

## Usage

- 入力欄にキーワードを入力すると、そのキーワードを含むピン留め項目を表示する

![](../image/adhoc-command/shell-destinations/example.png)

## Settings

この機能は初期状態で有効になっている。アプリケーション設定の `拡張機能` にある `ピン留めした項目を表示する` で切り替える。

![](../image/adhoc-command/shell-destinations/setting.png)

## Per-Key Behavior

|押下キー|動作|
|--|--|
|`Enter`|項目を開く|
|`Ctrl-Enter`|フォルダーを開く(ローカルパス項目のみ)|
|`Alt-Enter`|プロパティを開く(ローカルパス項目のみ)|
