# Currency Converter

通貨単位を変換して表示する機能です。機能を有効にすると、次の形式で入力できます。

```
数値 元の通貨 in 変換後の通貨
```

例:

```
100 usd in jpy
```

日本円は`jpy`のほか、`yen`でも指定できます。`yen`は`jpy`として扱われます。

結果は変換後の通貨単位で表示されます。結果を実行すると、変換後の数値だけをクリップボードへコピーします。

## データ取得元

為替レートは、次のデータ取得元から取得します。

https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@YYYY-MM-DD/v1/currencies/eur.json

`YYYY-MM-DD`には原則として実行日の日付を指定します。当日のデータ取得に失敗した場合は前日のデータを使用します。取得したデータはキャッシュとてし保持し、同日中はキャッシュを再利用します。

当日・前日のデータを取得できない場合、この機能は利用できません。為替データはユーロを基準としています。

## 注意事項

為替レートは外部サービスから取得するため、データの正確性を保証しません。また、データ提供元のサービスの継続性も保証しません。サービスの障害や仕様変更などにより、通貨変換を利用できない場合があります。
