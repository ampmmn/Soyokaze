# Command Execute > Files And Folders

コマンド種別`ファイル` `フォルダ`に対して、別のコマンドを関連付けるための設定画面。  
コマンドを登録しておくと、選択中の候補が`ファイル` `フォルダ`の場合に、任意のキー入力からコマンドを実行してファイルを開くことができる。

![](../../image/window/app-settings/command-execute/files-and-folders/settings.png)

上記の場合、`Ctrl-E`で`vim`というコマンド、`Ctrl-S`で`stirling`というコマンドを実行できる。  
コマンド種別`ファイル`または`フォルダ`の候補が選択されている状態で、登録したキー入力をすると、対応するコマンドを実行することができる。

設定したコマンドは下記の通り、ガイド欄に表示される。
