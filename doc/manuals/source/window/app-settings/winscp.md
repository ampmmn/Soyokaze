# Extension > WinSCP

![](../../image/adhoc-command/winscp-appsetting.png)

- `機能を有効にする`  
[WinSCPのセッション一覧を表示する](/adhoc-command/winscp)機能を有効にする。
- `ポータブル版のWinSCPを利用する`  
インストール版のWinSCPではなく、ポータブル版のWinSCPを使用している場合に使用する設定。  
`WinSCP.exeのパス`欄で指定した実行ファイルを用いる。
- `WinSCP.exeのパス`  
ポータブル版のWinSCPを使用している場合の`WinSCP.exe`のパスを指定する。
