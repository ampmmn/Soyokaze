# Extension > QR Code Generation

![](../../image/adhoc-command/qrcode/appsetting.png)

`拡張機能` > `QRコード生成` で QR コード生成機能を設定する。

- `機能を有効にする` で機能を有効／無効にする。
- `発動キーワード` に入力した文字列が起動キーワードとなる。初期値は `qrcode`。
- `誤り訂正レベル` は L、M、Q、H から選択する。レベルを上げると破損に強くなる一方、格納できる文字数は少なくなる。

詳細は[QRコード生成](../../adhoc-command/qrcode.md)を参照。
