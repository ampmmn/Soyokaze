(extensions-switch-window)=
# Extensions > Switch Window

ウインドウ切替関連機能に関する設定を行う画面

![](../../image/window/app-settings/switch-window/setting.png)

- `ExcelやLibreOffice Calcのシート名による選択を有効にする`  
入力画面を表示した時点で開いているExcel / LibreOffice Calcのシート名の一覧を候補として検索し、それを実行したら該当するシートをアクティブにする  
機能を利用するためには製品版Excel(デスクトップ版) または LibreOfficeがインストールされている必要がある
  - `プレフィックス`  
候補を表示するためキーワードを指定する  
キーワードを入力した時点で、シートの一覧が表示される
初期値は`xj` (e`x`cel `j`ump の略)
- `PowerPointのスライドタイトルによる選択を有効にする`  
入力画面を表示した時点でアクティブなPowerPointプレゼンテーションのスライドタイトルを候補として検索し、それを実行したら該当するシートをアクティブにする  
機能を利用するためには製品版PowerPoint(デスクトップ版)がインストールされている必要がある
  - `プレフィックス`  
候補を表示するためキーワードを指定する  
キーワードを入力した時点で、スライドの一覧が表示される
初期値は`pj` (`p`owerpoint `j`ump の略)
- `Outlookのフォルダ選択を有効にする`  
入力画面を表示した時点で起動しているOutlookのメールフォルダ名の一覧を候補として検索し、それを実行したら該当するフォルダを選択する  
機能を利用するためには製品版Outlook(デスクトップ版)がインストールされている必要がある
  - `プレフィックス`  
候補を表示するためキーワードを指定する  
キーワードを入力した時点で、フォルダの一覧が表示される
初期値は`ol` (`o`ut`l`ook の略)
