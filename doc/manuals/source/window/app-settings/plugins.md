# Plugins

インストールされているプラグインの有効状態と、コマンド検索時の優先度を設定する画面。

![](../../image/window/app-settings/plugins/setting.png)

## プラグイン一覧

プラグインごとに、次の情報を確認することができる。

- `有効`
  - プラグインが有効かどうかを表示する
  - プラグインを選択して右クリックすると、有効と無効を切り替えることができる
- `プラグイン名`
  - プラグインの表示名を表示する
- `優先度`
  - コマンド検索時の優先度を表示する
  - 数値が大きいプラグインほど先に検索される
- `バージョン`
  - プラグインのバージョンを表示する
- `説明`
  - プラグインの説明を表示する

## 優先度の変更

1. 優先度を変更するプラグインを一覧から選択する
2. `優先度変更`を選択する
3. 優先度を入力して確定する

![](../../image/window/app-settings/plugins/priority.png)

優先度には`0`から`10000`までの整数を指定できる。値が大きいプラグインから順に検索され、同じ優先度のプラグインはロードされた順序で検索される。

## 設定の保存

変更内容は、アプリケーション設定画面で`OK`を選択したときに保存される。`キャンセル`を選択した場合、画面を開いてから行った変更は破棄される。

無効にしたプラグインはDLL自体はロードされるが、コマンド検索の対象から除外される。プラグインの追加や削除を反映するには、{{ project }}を再起動する必要がある。
