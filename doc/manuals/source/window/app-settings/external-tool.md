(externaltool)=
# ExternalTool

本アプリから利用する外部ツールに関する設定画面。

![](../../image/window/app-settings/external-tool/setting.png)

- `ブックマーク検索／Web履歴検索においてEdge以外のWebブラウザも利用する`  
ブックマーク検索／Web履歴検索機能において、外部ツールを利用できる
  - `Chromeを使う`  
外部ツールとしてChromeを使う  
  - `別のWebブラウザを指定する`  
外部ツールとしてChrome以外のWebブラウザを使用する場合はこちらを選択する。  
こちらを選択した場合、下記の項目を指定する必要がある。
    - `アプリ表示名`  
この外部ツールを使うコマンドが候補欄に表示されるときに使う表示名を指定する
    - `実行ファイルパス`  
ブラウザの実行ファイルのパスを指定する
    - `パラメータ`  
ブラウザ起動時のコマンドラインパラメータを指定する。  
`$target`というキーワードを実際のURLに置き換える。  
(基本的にはここを変更する必要はない)
    - `設定データフォルダ`  
指定したWebブラウザのブックマークや履歴の情報が保存されたフォルダのパスを指定する。  
関連機能: [ブックマーク検索](/adhoc-command/bookmarks)、[Web履歴検索](/adhoc-command/webhistory)
- `コマンドからURLを開くとき、既定のブラウザではなく、上記のWebブラウザを使う`  
URLを参照するコマンドを実行したときや、入力欄にURLを直接入力したときに、ここで設定したWebブラウザが使われる。

(externaltool-restrictions)=
### Restrictions

- ブックマーク検索機能とWeb履歴検索機能はChromiumベースのWebブラウザに対応している
  - これらの機能で参照する設定データのフォルダは下記の構造を想定している  
この構造になっていないWebブラウザについては、ブックマーク検索とWeb履歴検索を利用することはできない
```
<設定データフォルダ>\
  Defailt\            設定データフォルタ直下にDefaultという名前のフォルダがあり、
    Bookmarks         その下にBookmarks、History という名前のファイルがある
    History
    ...
```
