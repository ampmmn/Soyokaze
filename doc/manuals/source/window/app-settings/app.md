# App

ランチャーの基本動作に関する設定画面  
主に入力画面を表示する際の動作の設定を行う。

![](../../image/window/app-settings/app/setting.png)

- `ランチャー呼び出しキー`
  - 入力画面を表示するためのホットキーを設定することができる
- `入力画面を非表示にして起動する`
  - 起動直後に入力画面を表示しない
- `入力画面を最前面に表示`
  - 入力画面を表示するとき、入力画面を他のウインドウより前面に表示するようにする
- `入力画面の表示位置`  
入力画面を表示するときの位置を以下の3つから選択できる
  - `前回の表示位置`  
前回と同じ位置に入力画面を表示する
  - `マウスカーソル位置`  
入力画面を表示するタイミングでのマウスカーソル位置に入力画面を表示する
  - `アクティブウインドウのモニター中央`  
アクティブなウインドウが表示されているモニターの中央位置に入力画面を表示する  
ただし、アクティブなウインドウがない場合は前回と同じ位置に表示する
- `すでにアクティブなときに呼び出しキーを押したら隠れる`
  - ランチャー呼び出しキーを押すたびに入力画面の表示/非表示が切り替わる
- `カーソル位置によるアクティブ切替`
  - 入力画面表示中、マウスカーソルが入力画面領域内へ移動した際に入力画面をアクティブ化し、領域外へ移動した際に非アクティブ化する。再度領域内へ移動した場合はアクティブ化する。
  - 非アクティブなときに半透明化する設定と組み合わせることで、入力画面の後ろにある内容を確認できるようにする目的の機能
- `フォーカスを失ったらウインドウを隠す`
  - 入力画面がフォーカスを失ったときに、入力画面を非表示にする
- `隠れるときに入力文字列を消去しない`
  - コマンドを実行せずに入力画面を非表示にする際に入力文字列を消去しない
    - 入力画面を次回再表示した際に、前回入力していた内容が維持される

(app-hotkey)=
### App HotKey

ランチャーアプリの入力ウインドウを呼び出すためのキー設定画面

![](../../image/common/hotkey-for-app.png)

- `ホットキーを設定する`  
修飾キー(`Alt` `Ctrl` `Shift` `Win`) + 任意のキーを同時押しすることによりアプリを表示する
  - `修飾キー`  
修飾キーを選択するためのもの。
  - 例: `Ctrl`のみチェックし、キーとして`A`を選択した場合  
Ctrl+A
  - `キー`  
文字を選択する
- `修飾キーの組み合わせ入力`  
修飾キー(`Alt` `Ctrl` `Shift` `Win`)を二つ組み合わせ入力することによりアプリを表示する方式  
同じキーを2回押す、あるいは、異なるキーを同時押しすることでアプリを起動することができる  
例: `Ctrl`キーの2回押し、あるいは、`Ctrl`+`Alt`キーの同時押し
  - `一つ目の入力`  
一つ目に入力する修飾キーを選択する
  - `二つ目の入力`  
二つ目に入力する修飾キーを選択する
