# Command Execute > Exclude Items

[`ファイル名を指定して実行`](/adhoc-command/pathfind) やアプリ、スタートメニューの候補から、表示したくない項目を除外できる。


![](../../image/window/app-settings/exclude-files/setting.png)

- `除外するファイルパス`
  - 登録したパスに一致するファイルを候補に表示しない。

- `追加`
  - クリックすると、ファイル選択ダイアログが表示される。選択したファイルが`除外するファイルパス`に追加される。
- `編集`
  - 選択したファイルパスを変更する。
- `削除`
  - 選択したファイルパスを削除する。
- `項目名の除外パターン`
  - 項目の表示名に対して、登録したパターンを大文字・小文字を区別せず部分一致で照合する。一致した項目は候補に表示しない。
  - 正規表現を使用できる。たとえば `^Copilot$` は、表示名が `Copilot` と一致する項目を除外する。
  - 無効な正規表現は追加・編集時に登録できない。
