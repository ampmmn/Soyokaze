(extensions)=
# Extensions

![](../../image/window/app-settings/extensions/setting.png)

- `Pythonを利用する拡張機能の設定`
  - `Python DLLへのパス`  
PCにインストールした`Python3`の本体DLLへのパスを指定する  
(Python3.12以降の`python3.dll`へのパスを指定する)
  - `簡易電卓機能を有効にする`  
入力画面に入力したテキストを数式として評価して、その計算結果を表示する  
![](../../image/window/app-settings/extensions/calculator.png)
  - `Enter`キーを押すと、計算結果をクリップボードにコピーする
- `システム関連の機能`
  - `コントロールパネル項目を候補として表示する`
    - コントロールパネル項目を候補として表示し、それを実行したら、該当するコントロールパネル項目を開く  
![](../../image/window/app-settings/extensions/control-panel-command.png)
  - `スタートメニュー／最近使ったファイルを候補として表示する`
    - ファイルを候補として表示・実行する
      - スタートメニューに登録されたプログラム
      - Windowsの`最近使ったファイル`に登録されたファイル
  - `アプリケーション(UWPアプリなど)を候補として表示する`
    - 実行環境にインストールされているアプリケーション(UWPアプリを含む)を候補として表示・実行する
  - `MMCスナップインを候補として表示する`
    - 実行環境にインストールされている[MMCスナップイン](/adhoc-command/mmcsnapin)を候補として表示する
  - `Windowsの設定を候補として表示する`
    - [Windows設定](/adhoc-command/windowssettings)の各ページ項目を候補として表示する
  - `環境変数を候補として表示する`
    - [環境変数](/adhoc-command/env)の一覧を候補として表示する
