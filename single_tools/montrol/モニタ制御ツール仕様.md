# 概要

実行環境に接続されたモニターの一覧の列挙、や輝度や入力の変更、サポートする入力の問い合わせを行える
Windows上で動作するCLIツールを作成する

プログラム名はmontrolとする

実装言語はC++(C++20)、VisualStudio2022を用いる

## 詳細

このツールは以下の機能を有する。

### モニターの列挙

論理モニターの列挙には、GDIの`EnumDisplayMonitors`を使用して`HMONITOR`を取得する。
各`HMONITOR`に対応する物理モニターの数を`GetNumberOfPhysicalMonitorsFromHMONITOR`で確認し、
`GetPhysicalMonitorsFromHMONITOR`でDDC/CI制御用の物理モニターハンドルを取得する。
モニター名の表示には`PHYSICAL_MONITOR`が保持する説明文字列を使用する。
取得した物理モニターハンドルは、使用後に`DestroyPhysicalMonitors`で解放する。

### 輝度の取得・変更

輝度の取得には、Windows Monitor Configuration API（`dxva2.dll`）の
`GetVCPFeatureAndVCPFeatureReply`を使用する。VCPコード`0x10`を指定し、
現在の輝度値と最大値を取得する。
輝度の変更には`SetVCPFeature`を使用し、VCPコード`0x10`と設定値を渡す。
ツールが扱う輝度値は0～100の正規化された整数値（パーセント）とする。
デバイスから取得したVCP値は、VCP最小値を0、`GetVCPFeatureAndVCPFeatureReply`で取得した最大値を上限として0～100へ線形変換する。
ツールからデバイスへ設定値を渡す場合は、0～100の値をデバイスの有効範囲へ逆変換し、
小数点以下は四捨五入する。指定値が0未満または100を超える場合はエラーとする。

### サポートする入力ソースの問い合わせ

入力ソースの対応一覧は、`GetCapabilitiesStringLength`でケイパビリティ文字列の長さを取得し、
`CapabilitiesRequestAndCapabilitiesReply`でMCCSケイパビリティ文字列を取得する。
取得した文字列のVCPコード`0x60`に対応する値の一覧を解析し、モニターがサポートする入力ソースを求める。
入力値に対応する表示名は、VESA MCCS標準値のエイリアス表を使用する。
標準表にない値は、ベンダー固有値として数値で表示する。
ケイパビリティ文字列を取得できない場合は、入力ソース一覧を空として扱い、取得失敗として記録する。

### 入力ソースの切替

入力ソースの切替には`SetVCPFeature`を使用し、VCPコード`0x60`と入力ソースのVCP値を渡す。
入力ソースがエイリアスで指定された場合は、VESA MCCS標準値に対応するVCP値へ変換してからAPIを呼び出す。
例えば`HDMI1`は`17`、`HDMI2`は`18`、`DisplayPort1`は`15`として扱う。
モニター固有の入力値を使用する場合は、問い合わせで得られた数値を直接指定できるようにする。


## コマンドラインオプション仕様

subversionやGitのように、第一引数でサブコマンドを記述し、後続のパラメータやオプションでコマンド固有の条件指定を行う。
ただし -h, -v が指定された場合はヘルプ、バージョン番号表示を行う

サポートするサブコマンドは下記

- query
- switch
- brightness

```
montrol.exe query <対象> [options]
montrol.exe switch <対象> [options]
montrol.exe brightness <対象> [options]
montrol.exe [-h | --help]
montrol.exe [-v | --version]
```

## コマンド説明

### query

モニターに対する問い合わせを実施する。

以下の問い合わせができる。

- 接続中のモニター一覧の出力
- 各モニターがサポートする入力一覧の出力
- 各モニターの現在の輝度値/最大値の出力

#### 書式

```
montrol query <対象> [オプション]
```

対象は `all` または 1はじまりのインデックス値

allを指定した場合はすべてのモニターの情報を表示する
インデックス値を指定した場合は該当するN番目のモニターの情報を表示する(複数指定は不可)


#### オプション

- `-h` `--help` : queryコマンドの説明、オプション一覧を表示する
- `-s` `--source` : モニター入力ソース一覧を表示
- `-b` `--brightness` : 対応するモニターの現在の輝度値を表示
- `-j` `--json` : 結果をJSON形式で出力する(単一指定)

`query all`でオプションを指定しなかった場合は、モニター一覧を表示するのみとする(入力ソース、輝度を情報に含めない)
`query 1`でオプションを指定しなかった場合は、該当モニターについての全情報を表示する(入力ソース、輝度)
`-s`と`-b`は同時指定可能

`-j`または`--json`はJSON形式で出力する。指定の有無で問い合わせる情報の種類は変わらない。
JSONでは`brightness`と`inputSources`のフィールドを常に出力する。
問い合わせ対象外の情報は、`brightness`を`null`、`inputSources`を空配列とする。
`query all`でオプションを指定しない場合も、このルールを適用する。


#### 出力例

##### -j`を指定せずに出力する場合

- `-b`を指定した場合は Brightnessを表示
- `-s`を指定した場合は Input Sourcesを表示

```
Detected Monitor Count: 2
[1] : <デバイス名1> 
  Brightness:
    50/100
  Input Sources:
    <id1> : <入力ソース名1>
    <id2> : <入力ソース名2>
    <id3> : <入力ソース名3>
[2] : <デバイス名2>
  Brightness:
    50/100
  Input Sources:
    <id1> : <入力ソース名1>
    <id2> : <入力ソース名2>
```

id1,id2,id3というのはGetCapabilitiesStringLengthとCapabilitiesRequestAndCapabilitiesReplyを通じて取得したMCCSケイパビリティ文字列から得られる、入力ソースを表すVCP値
入力ソースは入力ソースに対応するエイリアス。例えば17はHDMI1, 18はHDMI2 など。


##### `-j`を指定する場合

```json
{
    "count": N,
    "devices": [
        {
            "index": 1,
            "displayName": "<デバイス名1>",
            "brightness": [50,100],
            "inputSources": [ {"id": <id1>, "displayName": "<入力ソース名1>"}, {"id": <id2>, "displayName": "<入力ソース名2>"},  {"id": <id3>, "displayName": "<入力ソース名3>"} ]
        },
        {
            "index": 2,
            "displayName": "<デバイス名2>",
            "brightness": [50, 100],
            "inputSources": [ {"id": <id1>, "displayName": "<入力ソース名1>"}, {"id": <id2>, "displayName": "<入力ソース名2>"} ]
        }
    ]
}
```

輝度を取得できなかった場合、`brightness`の値は`null`とする。
入力ソースを取得できなかった場合、`inputSources`は空配列とする。
モニター名を取得できなかった場合、`displayName`は空文字列とする。

### switch

モニターの入力ソースを切り替える

```
montrol switch <対象> <入力ソース>
```

対象は1ベースのインデックス値
該当するN番目のモニターに対して入力ソース切替を行う

対象は「対象番号、入力ソース」の組を空白区切りで複数指定できる。
指定された組はコマンドライン上の左から右の順番で処理する。
対象番号の重複も許可し、指定順に順次処理する。
allは許可しない

入力ソースとしてVCP値またはエイリアスを指定することができる。

入力ソースのエイリアスは大文字・小文字を区別しない。
入力ソースの数値指定は0～255の整数値を許可し、モニターのケイパビリティにない値も送信可能とする。
エイリアスにも数値にも変換できない値はエラーとする。
対象番号と入力ソースの組が不足している場合、または存在しない対象番号が指定された場合はエラーとする。

1つのモニターの設定に失敗した場合メッセージを表示するが処理は継続する(後続のモニターのソース変更を試みる)

#### オプション

- `-h` `--help` : switchコマンドの説明、オプション一覧を表示する

#### 設定例

```
# 1つめのモニターをHDMI1, 2つめモニターをDisplayPort1に切替え
montrol switch 1 HDMI1 2 dp1
# VCP値で指定する例
montrol switch 1 17 2 15
```

### brightness

モニターの輝度値を変更する

```
montrol brightness <対象> <輝度値>
```

対象は all または 対象は1ベースのインデックス値 を指定できる
該当するN番目のモニターに対して輝度設定を行う

インデックス値を指定した場合、複数の対象を指定できる
(allの場合は複数指定できない)

allとインデックスの混在はエラー
対象のインデックス番号が重複しても順次処理する。
対象と輝度値の引数ペアが不足した場合はエラー
存在しないモニターのインデックス番号が指定された場合はエラー

1つのモニターの設定に失敗した場合メッセージを表示するが処理は継続する(後続のモニターの輝度変更を試みる)
輝度値は0～100の整数値を指定する。
指定された対象はコマンドライン上の左から右の順番で処理する。
`all`を指定した場合は、すべてのモニターに同じ正規化輝度値を設定する。

#### オプション

- `-h` `--help` : brightnessコマンドの説明、オプション一覧を表示する

#### 設定例

##### すべてのモニターの輝度を変える

```
montrol brightness all 20
```

##### 単一のモニターの輝度を変える

```
montrol brightness 1 40
```

##### 複数のモニターの輝度を変える

```
# 1つ目のモニターの輝度を20, 2つ目のモニターの輝度を40に設定
montrol brightness 1 20 2 40
```


### その他のオプション

- `-h` `--help` を指定したらヘルプを表示する

- `-v` `--version` のどちらかを指定したらバージョン番号を表示する(両方指定してもエラーにはしない)

- 何もオプションを指定せずに実行したときはヘルプを表示して終了する

## ヘルプの形式

Pythonの argparseがサポートする形式の様な形にしたい

## バージョン番号

バージョン番号の形式は`x.y.z`とする

例: 0.0.1

出力例: `montrol 0.0.1`

## その他留意事項

- VCP値と入力エイリアスの対応表はハードコードで保持する。
  - `vga1` / `vga` = 1
  - `dvi1` / `dvi` = 3
  - `dvi2` = 4
  - `composite` = 8
  - `svideo` / `s-video` = 9
  - `dp1` / `dp` / `displayport` = 15
  - `dp2` = 16
  - `hdmi1` / `hdmi` = 17
  - `hdmi2` = 18
  - `usbc` / `usb-c` / `typec` / `type-c` = 27
- 入力エイリアスは大文字小文字を区別しない
- このプログラムで扱う輝度値の範囲は0～100とする。(query, brightness共通)
  - デバイスにより最小値、最大値は異なる可能性があるが、デバイスが返す有効範囲内に対し0～100の値をマッピングする。
- DDC/CI非対応モニターは一覧として表示するが、操作不可とする。
- モニターのインデックスは、その実行時の列挙順に基づく一時的な番号とする。実行間で番号が維持されることは保証しない。
- DDC/CI通信を行うWindows APIはリトライしない。各APIの呼び出しは1回のみとし、失敗時は即時にエラーとして扱う。
- 複数モニターを処理する場合、1台の処理に失敗しても残りの対象を継続して処理する。1件以上失敗した場合、処理完了後の終了コードは失敗とする。
- `-v`または`--version`では、バージョン番号を`montrol x.y.z`の形式で標準出力へ表示する。
