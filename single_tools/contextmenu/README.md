# contextmenu

`contextmenu` は、指定したファイルやフォルダのWindowsコンテキストメニュー(右クリックメニュー)を表示するコマンドラインツールです。

## 基本書式

```text
contextmenu.exe [--nowait] [--position=<x位置>,<y位置>] <path> [<path> ...]
```

## 使用例

ファイルのコンテキストメニューを表示します。

```text
contextmenu.exe "C:\work\sample.txt"
```

フォルダのコンテキストメニューを表示します。

```text
contextmenu.exe "C:\work\sample"
```

複数のファイルやフォルダを指定できます。

```text
contextmenu.exe "C:\work\a.txt" "C:\work\b.txt" "C:\work\sample"
```

パスに空白が含まれる場合は、パス全体を引用符で囲んでください。

## 表示位置

コンテキストメニューは、デフォルトではマウスカーソルのある位置に表示されます。

`--position=<x位置>,<y位置>` を指定すると、指定したスクリーン座標にメニューを表示します。

```text
contextmenu.exe --position=100,200 "C:\work\sample.txt"
```

座標は複数枚のモニターを含む仮想デスクトップ上のスクリーン座標です。負の値を指定すると、負の方向のモニターに対して表示できます。

メニューが画面からはみ出す場合は、Windowsが自動的に画面内へ移動します。

## `--nowait`

`--nowait` を指定すると、コンテキストメニューを表示する後続プロセスを起動し、呼び出し元のプロセスはメニューの表示を待たずに終了します。

```text
contextmenu.exe --nowait "C:\work\sample.txt"
```

後続プロセスは、メニューを閉じて選択した項目の処理が完了するまで動作します。

## 複数パスの動作

複数のパスを指定した場合、親フォルダごとにまとめてメニューを表示します。

- 同じフォルダに属する複数のパスを指定した場合は、Explorerの複数選択と同じメニューを表示します。
- 異なるフォルダに属するパスを指定した場合は、フォルダごとに順番にメニューを表示します。

あるフォルダのメニューでコマンドを選択すると、そのコマンドを実行して終了します。
キャンセルした場合は、次のフォルダのメニューを表示します。

## 存在しないパス

存在しないパスを指定した場合は、そのパスを対象から除外します。

対象のパスが1つも存在しない場合は、何も表示せずに終了します。

## 項目の選択後の動作

メニューで項目を選択すると、選択された項目を実行します。

Windowsシェルは「プロパティ」のようにダイアログを表示する項目を非同期に処理するため、`contextmenu.exe` はその項目の処理が終わるまでプロセスを終了させません。ダイアログが表示された場合は、そのダイアログを閉じるまで待機します。

ダイアログを表示しない項目(コピーや削除など)を選択した場合は、処理の完了を確認するため最大4秒ほど待機してから終了します。

## 注意事項

- Windows専用のツールです。
- メニューに表示される項目と、選択した項目を実行したときの動作は、Windowsシェルおよび対象のファイルやフォルダに関連付けられたシェル拡張に依存します。
- 相対パスを指定した場合は、実行時のカレントディレクトリを基準に処理されます。
- メニューを閉じずに終了した場合(フォース終了など)は、選択した項目は実行されません。
