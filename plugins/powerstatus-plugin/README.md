# powerstatusプラグイン

## 概要

バッテリー残量を定期的に監視し、設定ファイルで定義したしきい値を上下回った場合にトーストで通知するプラグイン

プラグイン初期化時に設定ファイルを読み込み、監視用のタイマーを開始する。  
取得した残量がしきい値を跨いだときだけ通知を行い、再度同じ方向へ跨ぐまでは通知を繰り返さない。

## 詳細

プラグイン初期化(Initialize)のタイミングで、DLLと同じディレクトリにある`powerstatus.yaml`を読み込む。

設定ファイルが読めない場合、または設定内容に不正がある場合は、エラーログを出力して監視を行わない。  
(プラグイン自体の初期化は成功として扱うため、プラグイン設定画面の一覧には表示される)

監視は本体のメインスレッド上で動作するメッセージ専用ウインドウのタイマーで行う。  
WM_TIMERは本体のメッセージループを通じて処理されるため、`LAUNCHER_FUNCTION_TABLE::PopupMessage`を安全に呼び出せる。

## 設定ファイルの仕様

- YAML形式
- ファイル名は`powerstatus.yaml`とする
- パスはDLLが存在するディレクトリ(`GetModuleFileName`で取得したディレクトリ)

|キー|必須|説明|
|-|-|-|
|`upper-threshold`|必須|上側しきい値。残量がこの値を上回ったら通知する(0〜100)|
|`lower-threshold`|必須|下側しきい値。残量がこの値を下回ったら通知する(0〜100)|
|`interval-seconds`|任意|監視間隔(秒)。既定値は10|

- `upper-threshold`は`lower-threshold`より大きい値を指定する
- `interval-seconds`は1〜86400の範囲で指定する
- バッテリー残量が未知(例: バッテリーを搭載していないデスクトップPC)の場合は監視を行わない

```yaml
upper-threshold: 80
lower-threshold: 20
interval-seconds: 10
```

## 通知の仕様

- 上側しきい値を上回ったら通知する
  - 一度上回ったら、下回るまでは次の通知をしない
- 下側しきい値を下回ったら通知する
  - 一度下回ったら、上回るまでは次の通知をしない
- 上側、下側はそれぞれ独立して状態を保持する
- アプリ起動時点ですでにしきい値を跨いでいた場合、初回の通知は行わない

### 通知例

- 上側: `バッテリー残量が 85% になりました(上側しきい値 80% を上回りました)`
- 下側: `バッテリー残量が 15% になりました(下側しきい値 20% を下回りました)`

## 検索機能について

このプラグインはキーワード検索によるコマンドは提供しない。  
プラグインAPIの仕様上、検索に関係する関数も定義する必要があるため、これらは空実装としている。
